# NextGen Token Website v2

Static website for NextGen Ecosystem (NGT).

Contract:
`0xc9ca82fb600517e0119c6dff589df421c0fb474f`

## Run locally
Open `index.html` directly, or run:
`python -m http.server 8080`

## Deploy to GitHub Pages
1. Push these files to the repository.
2. GitHub → Settings → Pages → Source: GitHub Actions.
3. Push to `main`; the included workflow deploys the site.

This site intentionally does not claim staking/APY or transaction auto-burn unless those functions are actually implemented in the deployed contract.
